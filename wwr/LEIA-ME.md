## Falta só uma coisa: as imagens

Eu não consigo baixar arquivos binários (fotos/PNG) automaticamente por aqui,
então o sobre.html já está apontando para os nomes de arquivo corretos dentro
de wwr/imagens/ — você só precisa baixar cada imagem do link abaixo e salvar
com o nome indicado, dentro da pasta imagens/.

| Salvar como            | Baixar de |
|-------------------------|-----------|
| imagens/logo.jpg        | https://byui-cse.github.io/wdd130-ww-course-pt/resources/images/logos/z-wwr-blue.jpg |
| imagens/hero.jpg         | https://byui-cse.github.io/wdd130-ww-course-pt/resources/images/rafting14_1024.jpg |

| imagens/instagram.svg    | https://byui-cse.github.io/wdd130-ww-course-pt/resources/images/icons/instagram-bw.svg |
| imagens/twitter.svg      | https://byui-cse.github.io/wdd130-ww-course-pt/resources/images/icons/x-bw.svg |

Como baixar: clique com o botão direito na imagem no link (ou abra o link e
use "Salvar como") e salve com o nome exato da tabela, dentro de wwr/imagens/.

Se preferir trocar por outras fotos/logos, tem mais opções em:
- https://byui-cse.github.io/wdd130-ww-course-pt/resources/wwr-image-repo.html
- https://byui-cse.github.io/wdd130-ww-course-pt/resources/wwr-logos-repo.html

Depois de salvar as 6 imagens, a página abre normalmente com Live Server.
